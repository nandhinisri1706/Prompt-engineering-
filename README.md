## Overview

PromptCraft AI is an interactive Prompt Engineering Lab built using Streamlit and Python. It allows users to explore different prompting techniques and observe how structured prompts influence the responses generated by a Large Language Model (LLM).

The application uses a language model through the Hugging Face Inference API to generate responses based on user input, selected prompting techniques, and configurable model parameters.

## Features

* Seven prompting techniques.
* Automatic prompt generation based on the selected technique.
* Interactive interface built with Streamlit.
* Custom task and question input.
* Adjustable temperature and maximum token parameters.
* Displays the generated prompt and LLM response separately.
* Error handling for API and connection issues.

## Prompting Techniques

1. **Zero-Shot Prompting:** Generates responses without providing examples.
2. **One-Shot Prompting:** Uses one example to guide the model.
3. **Few-Shot Prompting:** Uses multiple examples to demonstrate the expected response pattern.
4. **Chain of Thought (CoT):** Encourages structured problem-solving with a concise explanation.
5. **Manual Chain of Thought:** Uses predefined steps to organize the problem-solving process.
6. **Tree of Thoughts (ToT):** Evaluates multiple possible approaches before selecting a suitable solution.
7. **MCOT:** Uses a structured multi-step reasoning approach.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate to the project directory:

```bash
cd Prompt_engineering
```

### 2. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Configure the API Token

Create a `.env` file in the project root directory and add your Hugging Face access token:

```env
HF_TOKEN=your_huggingface_token
```

Replace the placeholder with your actual token.

### 4. Run the Application

```bash
python -m streamlit run app.py
```

The application will open in your browser, usually at:

```text
http://localhost:8501
```

## How to Use

1. Open the PromptCraft AI application.
2. Select one of the seven prompting techniques.
3. Enter a question or task in the input field.
4. Adjust the temperature and maximum token settings.
5. Click the Generate Response button.
6. Review the generated prompt.
7. Read the response produced by the language model.

## Model Parameters

### Temperature

Controls the randomness of the generated response. Lower values generally produce more focused outputs, while higher values can produce more varied responses.

### Maximum Tokens

Specifies the maximum number of tokens generated by the model for a response.

## Error Handling

The application displays an error message when an API request fails. Errors may occur due to exhausted inference credits, invalid API tokens, unavailable models, provider restrictions, or network issues.

The Hugging Face Inference API may require available inference credits. A valid access token alone does not guarantee that model inference is available.

## Security

* Store API tokens in the `.env` file.
* Never commit API tokens or other secrets to a public repository.
* Add `.env` to `.gitignore`.
* Revoke and replace any token accidentally exposed publicly.

Example `.gitignore`:

```text
.env
__pycache__/
*.pyc
```
